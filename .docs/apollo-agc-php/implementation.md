# Implementation: apollo-agc-php

Plan: [`plan.md`](plan.md)

## Changes applied

### 1. Skelet: de maanlander valt zichtbaar op de pagina

Verified by two builders. From the command line: `composer install` succeeded, `vendor/bin/phpunit` passed with 49 tests and 3622 assertions, and `vendor/bin/phpstan analyse` reported no errors at level 8. `curl -si /` returned the CSP from §4 and `nosniff`, and `/api.php` set the cookie `apollo` with `HttpOnly` and `SameSite=Strict`. Seven invalid requests against the running server each returned the expected status with only `{"error":…}`. In Chrome: the page showed "Start landing", the lander fell on the Canvas from 15240 m to 0 m in 172.2 s with the altitude dropping on every tick, and the page showed "Outcome: crashed". Over 130 ticks the peak number of concurrent `/api.php` requests was 1. The only console message was a 404 for the browser's own `/favicon.ico` request.

- `composer.json`: project skeleton per plan §1 (PSR-4 autoload, PHPUnit and PHPStan as dev dependencies, scripts)
- `composer.lock`: generated by `composer install`; the project tracks it
- `phpunit.xml.dist`: PHPUnit config (testsuite `tests/`, cache in `.phpunit.cache`, fails on risky and warning)
- `phpstan.neon.dist`: PHPStan level 8 over `src` and `tests`
- `.gitignore`: ignores `/vendor/` and `.phpunit.cache/`
- `LICENSE`: MIT licence (copyright holder "jester1979", year 2026, chosen by the builder)
- `public/index.php`: HTML shell with start button and canvas, sends the CSP from §4 and `nosniff`, no inline script or style
- `public/api.php`: tick endpoint per §4 (session cookie `HttpOnly` and `SameSite=Strict`, strict mode, `display_errors` off)
- `public/assets/app.js`: ES module, POSTs start, then ticks every 100 ms (await, render, delay; never two in flight), shows the outcome
- `public/assets/views/landing.js`: Canvas view of the lander, surface, altitude bar and readouts
- `public/assets/style.css`: page styling
- `src/Http/TickRequest.php`: the only input check, 10 rules in the order of §4, fixed error texts
- `src/Http/ApiController.php`: handles start and tick, maps errors to `{"error": …}`, turns a `Throwable` into 500 "Internal error" (details only to the logger)
- `src/Http/ApiResponse.php`: status and body value object
- `src/Http/Action.php`: enum for start and tick
- `src/Http/InvalidRequest.php`: exception carrying the status and a fixed message
- `src/Simulation/Simulation.php`: `start()` and `tick()`, builds the §10 response with placeholders for the DSKY, agc and log fields
- `src/Simulation/SessionStore.php`: keeps the `Simulation` in `$_SESSION` by reference
- `src/Simulation/TickInput.php`: validated tick input (keys, rod, speed)
- `src/Simulation/ChapterNotAvailable.php`: raised for a valid chapter id that is not built yet; the controller returns 501
- `src/Physics/Body.php`: Moon and Earth with mu and radius
- `src/Physics/StateVector.php`: position and velocity, altitude, radial and horizontal velocity, ground-track angle
- `src/Physics/Vehicle.php`: mass, thrust, isp, throttle and pitch
- `src/Physics/Integrator.php`: RK4 with gravity, thrust and fuel burn, fixed 0.1 s step
- `src/Agc/Agc.php`: minimal AGC state (computer, major mode, mission time)
- `src/Agc/Computer.php`: enum CM and LM
- `src/Dsky/Key.php`: key enum, needed by tick rule 7
- `src/Chapter/Chapter.php`: chapter interface per §4
- `src/Chapter/ChapterId.php`: chapter enum with `computer()` and `next()`
- `src/Chapter/Outcome.php`: Success, Crashed, OutOfFuel, Missed
- `src/Chapter/Landing/LandingChapter.php`: unpowered fall from PDI altitude, contact check, outcome
- `src/Scenario/StartStates.php`: landing start state and LM vehicle data
- `tests/Http/TickRequestTest.php`: one failing case per rule (28 cases), rule order, and the valid cases
- `tests/Http/ApiControllerTest.php`: error-only body, start then tick, 501, and a `Throwable` gives 500 with no path
- `tests/Physics/IntegratorTest.php`: circular orbit, free fall, fuel burn to 0.1%, engine cutout
- `tests/Chapter/LandingChapterTest.php`: altitude drops every tick, the lander crashes, a finished chapter stays frozen
- `tests/Chapter/ChapterIdTest.php`: mission order and computer per chapter
- `tests/Simulation/SimulationTest.php`: response shape, speed times 0.1 s, outcome at contact
